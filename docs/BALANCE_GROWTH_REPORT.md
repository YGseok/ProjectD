## 성장 가정

아이템 없이 시작 구성 그대로만 보는 F-4 기준선(`docs/BALANCE_REPORT.md`)과
달리, 이 리포트는 "런 중 실제로 강해지면 후반 난이도 절벽이 완화되는가"를
보려고 전투 직전 주머니를 "지금까지 몇 번째 전투인가"(global index =
(라운드-1) x 5 + 방번호, 0~14)에 따라 단순 규칙으로 키운다. 정책은 3종 —
**균형**(전투 2번마다 공격/방어 다이스를 번갈아 +1개), **공격 몰빵**
(전투 2번마다 공격만 +1개), **방어 몰빵**(전투 2번마다 방어만 +1개) —
세 정책 모두 `DiceBag.MAX_DICE`(6)에서 그 주머니의 개수 성장이 멈춘다.
다이스 면 개수는 세 정책 공통으로 global index 5부터 D4->D6, 10부터
D8로 승급한다("한 라운드에 아이템 3~4개 얻는 정도의 성장"이라는 가정 —
실제 상점/보상 픽과 완전히 같을 필요는 없음). 시작 스킬은 캐릭터별
**슬롯 0만** 고정 부여(정책 효과만 보기 위해 스킬 변수를 고정) — F-4
기준선처럼 매 trial마다 골드/눈금 인벤토리는 0/빈 배열로 초기화한다.

## 시뮬 조건 (재현용)

- 캐릭터 8종 x 시작 스킬 슬롯 0 x 정책 3종(균형/공격 몰빵/방어 몰빵) x
  {라운드 1~3 x 방 0~4(일반, 방4=보스) + 라운드 1~3 x 방 1~3(정예)} =
  576개 조합 x 100판/조합 (전투 57600판).
- 몬스터 배정 시드는 F-4b와 동일(`FIXED_PLAN_SEED=20261007`, 정예는
  `+104729`)로 고정 — 기준선과 같은 라운드별 몬스터를 상대한다.
- 다이스 굴림(RNG)은 조합마다 100판 독립적으로 다시 굴림 — 재실행하면
  수치는 소폭 달라질 수 있다(시드 고정 대상이 아님).
- 교환 120회(`MAX_EXCHANGES`)를 넘기면 타임아웃으로 집계(승리/패배 아님).
