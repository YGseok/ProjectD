# 캐릭터 표정 35장 — 사용자 피드백 체크리스트 (2026-11-12)

대상: `qa_out/r3/r52_faces35.png` (새 화풍 표정). 각 캐릭터 작업 시 아래 항목 **전부**를 요청문에 넣고, 결과도 전부로 검사한다.
공통 검사: 손 2개 + 각 손이 어느 소매/팔에서 나오는지(한쪽에서 손 두 개 금지, 떠다니는 손가락 금지) · 주사위 면별 눈금(1~6, 보이는 면 서로 다름, 표준 배치) · 배경 제거 후 어두운 배경에서 구멍 · **원본 표정 이미지에도 같은 문제가 있으면 원본도 수정**.

## 광전사
- [ ] 상처가 표정마다 바뀜 → 원본 표정 이미지의 상처와 위치·모양 일치
- [ ] 가슴 위아래가 눌려 납작함 → 원본도 그런지 확인(원본도 눌려 있으면 원본 교정). 흉상 크기에 맞추느라 생긴 것 같으면 먼저 기존 방식으로 재시도, 안 되면 반신까지 그린 뒤 크롭

## 매혹사
- [ ] 머리 장식 쪽 정체 불명 조각(첨부 1번: 주황 삼각형) 삭제
- [ ] 주사위 눈금 이상 → 수정(원본도 문제면 함께)
- [ ] 주사위 띄우는 손을 매번 그릴 필요 없음
- [ ] 기쁨: 눈이 살짝 열려 이상 → 확실히 뜨거나 감기
- [ ] 화남: 피부 톤이 밝아짐 → 다른 표정과 맞춤 / 볼을 부풀리고 삐친 듯 화난 표정
- [ ] 슬픔: 안 슬퍼 보임, 눈물과 표정이 따로 놂 → 더 슬프게
- [ ] 고통: 살짝 좋아하는 듯 에로틱한 느낌, 상처 표현 없음

## 수호자
- [ ] 기본·기쁨·슬픔이 똑같음 → 감정 표현이 약한 캐릭터지만 표정끼리 구분되게
- [ ] 고통: 상처 표현 없음, 고통이 약해 보임 → 눈을 질끈 감고 애써 참는 모습

## 폭발병
- [ ] 얼굴 주변 이펙트(반짝 별표, 분노 번개, 씩씩대는 구름 등) 제거 — 눈 속 반짝임은 유지
- [ ] 가슴이 원본보다 작아짐 → 원본 크기로(눌린 느낌은 없음)

## 주술사
- [ ] 모든 표정에서 목이 떠 있는 듯 어색 → 머리·목 위치 맞는지 확인·교정
- [ ] 책의 주사위 눈금 이상 → 수정(원본도 문제면 함께)
- [ ] 첨부 2번(보라 장식) 애매하게 잘림 → 정리(원본도 확인)
- [ ] 표정 변화가 적고 냉소적인 캐릭터 → 표정 전반 다시 만들기
- [ ] 책을 든 캐릭터 → 얼굴 주변에 손을 하나 더 올리면 손 3개가 됨, 금지

## 곡예사
- [ ] 손 3개 → 손 2개, 한쪽 방향에서 손 두 개 나오지 않게 / 주사위 띄우는 손 매번 필요 없음
- [ ] 머리 위 표정 얼굴 장식이 깨짐 → 장식 얼굴에도 같은 감정 표정
- [ ] 기쁨: 눈이 살짝 열림 → 확실히 뜨거나 감기
- [ ] 고통: 견디는 느낌보다 솔직하게 아파하는 느낌

## 해적
- [ ] 무난함. 단, 해적치고 피부가 밝음 → **원본 전신부터** 피부 톤 조정 후 표정에도 반영

## 2차 피드백 (2026-11-12, 수정본 r54 확인 후)
- 광전사: 웃음 — 눈썹이 사라짐 → 눈썹 복원 / 가슴 여전히 눌림 → 원본(전신)부터 가슴 사이즈를 키우는 안 검토 / 슬픔 — 분함·울컥하는 감정을 억누르는 표정 / 분노 — 지금 것 유지 + 더 격하게 화내는 안 추가로 비교
- 매혹사: 화남 — 볼을 너무 부풀림 → 퉁명스럽게 살짝만. 여성스럽고 매력 있는 캐릭터(아이 같지 않게)
- 수호자(자체 점검): 기쁨 수정본도 기본과 거의 같음 → 기본=무표정(입 일자), 기쁨=확실한 미소, 슬픔=처진 눈썹·내리깐 눈으로 구분
