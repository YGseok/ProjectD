# 아트 작업 순서표 (Art 스레드)

> 2026-11-11 사용자 지시: "순서대로 처리할 수 있도록 기억해서 제시. 그때그때 발생하는 일에 따라 지금 하는 일이 계속 바뀌지 않게."

## 운영 규칙

- **위에서부터 하나씩 처리한다.** 한 항목이 끝나면(사용자 컨펌 또는 반영) 다음 항목으로 간다.
- **진행 중인 항목에 대한 피드백**은 바로 반영한다(같은 항목 안의 일).
- **새로 생긴 요청**은 지금 하던 일을 끊지 않고 이 표의 알맞은 자리에 끼워 넣은 뒤, 어디에 넣었는지 사용자에게 알린다. 사용자가 "급함/먼저"라고 하면 그때만 맨 위로.
- 사용자에게 진행 상황을 보고할 때는 항상 이 표 기준으로: **지금 항목 / 다음 항목 / 남은 개수**.
- 생성 대기 시간에는 같은 단계의 다음 항목을 다른 GPT 스레드에서 미리 진행해도 되지만, **사용자에게 보여주는 순서는 이 표대로**.
- 이 표에 없는 몬스터(게임 목록에서 빠진 해골 전사·해골 궁수·해골 기사·망령 병사)는 작업하지 않는다.
