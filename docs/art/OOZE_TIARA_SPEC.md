# 점액 군주 티아라 — 목표 체크리스트 (사용자 피드백 누적, 2026-11-12)

결과는 아래 **전부** 통과할 때만 사용자에게 가져간다.

1. 머리 모양: 원안(om6a)의 둥글고 높은 점액 머리 그대로. 눌림·납작함·깎임 없음 (om7~9 지적)
2. 씌운 느낌 없음: 머리 위에 반투명 띠·막·뚜껑·돔·후광 등 덧입힌 것 없음 (om11, om15 지적 "머리 위에 뭐 씌웠다")
3. 링이 걸린 부분이 두툼하게 말리지 않음 — "말린 콘돔" 금지 (om9 지적)
4. 쓰는 방식: 티아라를 **기울여서 쓴** 상태, **흘러내린 느낌**(한쪽이 이마 쪽까지 내려옴, 균형이 어긋남) — 빨간 선에 얽매일 필요는 없음
5. 가라앉음: 슬라임이라 티아라 **절반 가까이가 머릿속으로 가라앉은** 상태. 나뉘는 기준은 위/아래가 아니라 **좌/우** — 왼쪽은 위쪽 끝까지 잠겨도 됨, **오른쪽 절반이 밖으로** 나옴
6. 잠긴 부분: **반투명하게 비침**(사용자 선택) — 단, 위에 덧칠한 것처럼이 아니라 점액 안쪽에 있는 것으로 읽혀야 함
7. 밖으로 나온 부분: 선명한 금색·에메랄드(바래지 않음)
8. 티아라 디자인·크기: om5에서 OK 받은 디자인(화려한 원안에서 약간 단순화) 유지, 장식 추가·확대·목걸이처럼 두르기 금지 (om13)
9. 나머지(얼굴·표정·입·혀·귀걸이·주사위·몸·대비·화풍)는 om6a와 동일
