### 수정 내역

1. **공용 헬퍼 신설** `code/systems/ui_kit.gd`(`UIKit`) — `make_section`(세로 구역 패널),
   `make_bar`(가로 HUD 띠), `make_stat_chip`(아이콘+큰 숫자+캡션), `make_progress_dots`
   (진행도 점), `style_primary_button`/`style_secondary_button`(주/보조 버튼 위계).
   M-2~M-4에서 재사용할 공용 컴포넌트로 설계(INBOX M-3 "공용 컴포넌트/헬퍼로 만들어
   K-3 CharacterTheme와 연결").
2. **제목 정리**: "던전 맵 (테스트 허브)" → "던전 맵"(`RunState.test_battle`일 때만
   "(테스트 전투)" 부기).
3. **HUD 바 신설**: 라운드/진행도(점 5개)/골드를 아이콘+큰 숫자+캡션 칩 3개로 묶은
   테두리 띠 하나로. `_hud_round_value_label`/`_hud_progress_dots`/`_hud_gold_value_label`이
   `_update_labels()`마다 갱신.
4. **범례를 테두리 띠로**: `UIKit.make_bar()`로 감싸 "떠 있는 느낌" 제거.
5. **상태 캡션**: 기존 RoomsClearedLabel(복잡한 분기 문구, "게임 클리어!" 등)은 삭제하지
   않고 13px 회색 캡션으로 격하해 HUD 바로 아래에 유지.
6. **버튼 위계**: 전투 입장만 `style_primary_button`(accent 꽉 채운 칠, 64px 높이,
   18px 폰트) — 나머지(상점/이벤트/스토리/정예/커스터마이징)는 `style_secondary_button`
   (어두운 배경+primary 테두리, 46px 높이, 14px 폰트). 정예 전투는 기존 빨간 테두리
   의도를 `tint` 매개변수로 유지하되 같은 버튼 틀(두께/모서리)로 통일.
7. **MapStrip 카드 높이 동적화**: 고정 130px 대신 "그 런에서 실제로 가장 많은 선택지를
   보여주는 방" 기준으로 계산(`_build_map_strip()`).
8. **DeckPanel 구역 패널화**: `_add_character_section`(얼굴 썸네일 40×40 + 이름 + 설명),
   `_add_skills_section`, `_add_bag_section`×2를 전부 `UIKit.make_section()`으로 테두리
   패널화. 빈 공간을 메우기 위해 **이벤트 주사위**(`EventDieVisual`)/**인벤토리**(눈금·
   다이스 보유 개수) 신규 섹션 추가 — 지금까지 이 정보는 character_select/CustomizePanel을
   열어야만 보였음.
9. **DeckPanel을 ScrollContainer로 감쌈**: 보유 스킬이 많이 쌓이면(런 후반) 섹션 총합이
   패널 고정 높이를 넘을 수 있어, 화면 밖으로 잘리는 대신 스크롤되게 함(ART-1a와 같은
   해법).
10. **(버그 발견 및 수정) `FocusNav.focus_style()`의 불투명 배경**: Godot이 포커스
    상태의 버튼을 그릴 때 기존 스타일 위에 "focus" 스타일을 겹쳐 그리는데, 기존
    `focus_style()`이 불투명 회색 배경을 썼던 탓에 **포커스된 주 행동 버튼이 보조
    버튼과 똑같이 회색으로 덮여버리는 버그**를 라운드 1 After 캡처에서 발견(화면
    진입 시 `grab_first_focus()`가 항상 첫 버튼을 포커스하므로 상시 발생). 배경을
    투명으로 바꿔 테두리만으로 포커스를 표시하도록 수정 — 전 화면 공통 유틸이라
    수정 효과가 모든 화면에 적용됨(검증은 `FocusNav.focus_style()`의 `border_color`만
    확인하는 기존 dice_test 단위 테스트와 무충돌).

### 라운드 2 — After 비평

캡처: 1번째 방, 2번째 방(상점+정예), 마지막 방(보스), 라운드 2, 보유 스킬 4개, 해적,
주술사.

- 주 행동 버튼이 즉시 눈에 띔(accent 꽉 채운 칠, 보조 버튼은 어두운 테두리) — **상 해결**.
- 개발용 문구 사라짐 — **상 해결**.
- HUD 바(라운드 큰 숫자 + 점 5개 진행도 + 골드 큰 숫자)로 위계 명확 — **상/중 해결**.
- DeckPanel: 기본 상태(스킬 없음)에서 6개 구역이 패널 안에 깔끔히 들어차고 바닥 여백이
  ~90px 수준으로 줄어듦(이전 ~200px) — **상 해결**. 스킬 4개인 상태에서는 ScrollContainer가
  작동해 스크롤바가 보이고 내용이 화면 밖으로 잘리지 않음 — **상 해결**.
- MapStrip 카드 높이가 그 런의 실제 내용(2~3줄)에 맞춰 타이트해짐 — **중 해결**.
- 범례가 테두리 띠 안에 들어와 "떠 있는 느낌" 해소 — **중 해결**.
- 캐릭터 3명(해적 밝은 청록/주술사 어두운 보라/견습 모험가 중간 핑크) 모두 배경·HUD
  테두리·버튼 accent·DeckPanel 테두리가 일관되게 그 캐릭터 색을 따름, 글자 대비 문제
  없음(K-3/L-3가 보장하는 대비비 계산을 그대로 재사용) — 신규 문제 없음.

**남은 "하" 수준 문제** (더 고치지 않고 다음 라운드로 넘김):
- 전투 버튼 옆 계열 아이콘이 아직 정해지지 않은 방(`family=""`)에서 작은 따옴표 모양
  글리프로 보임(`FamilyIcon` 기존 동작, M-1 이전부터 있던 문제라 이번 범위 밖).
- DeckPanel 얼굴 썸네일(40×40)이 작아서 "얼굴"이라기보다 색 점에 가까움 — 원화 입고 전
  플레이스홀더 실루엣의 근본적 한계(ART-1b/c 완료 전까지는 구조적으로 더 개선하기 어려움).
- 범례 아이콘이 여전히 작고(16px) 촘촘함 — 정보량 대비 자리는 충분해 긴급하지 않음.

남은 문제가 전부 "하" 수준이라 M-1은 이 라운드에서 종료.

### Before/After 요약

**Before**: 개발용 문구 노출, 버튼 3~5개가 전부 같은 평범한 회색 사각형이라 주 행동이
안 보임, 우측 패널 하단 200px가 빈 공간, 라운드/골드가 같은 크기 평문.
**After**: 전투 버튼만 캐릭터 accent색으로 꽉 채워 압도적으로 눈에 띔, 라운드/진행도
(점)/골드가 HUD 칩 3개로 정리, 우측 패널이 구역 패널 6개(캐릭터/스킬/공격/방어/이벤트
주사위/인벤토리)로 가득 차고 넘치면 스크롤, 방 카드 높이가 내용에 맞게 타이트해짐.
부수적으로 전 화면 공통 버그(포커스 시 커스텀 버튼색이 회색으로 덮이는 문제)를 발견해
`FocusNav`에서 고쳤다.

### 수정 내역

1. **제목 정리**: dungeon_map M-1과 같은 패턴 — "전투" (+ `RunState.test_battle`이면
   "(테스트 전투)" 부기).
2. **디버그 줄 QA/디버그 빌드 전용화**: 기존 `monster_debug_info_label`(`[QA] 공격
   2D4 · 방어 1D4` + 스킬/보스 상세)은 `OS.is_debug_build()`일 때만 보이게 하고, 화면
   우측 하단 구석(x1146~1276, y552~712)의 작은 10px 글자로 격하했다 — 에디터/디버그
   빌드(지금 이 QA 캡처 환경 포함)에서는 여전히 보이지만 내보낸 릴리즈 빌드에서는
   완전히 사라진다(INBOX M-2 "QA/디버그 플래그가 켜졌을 때만 표시").
3. **상단 HUD 3구역 재설계** (`_setup_combat_hud()`, dungeon_map.gd의
   `_setup_hud_bar()`와 같은 패턴으로 `UIKit`을 재사용해 런타임에 생성):
   - 좌(플레이어): 얼굴 썸네일(`CharacterArt.load_face_thumb`) + 이름 + 두꺼운(28px)
     HP 바(숫자 겹쳐 표시).
   - 중앙: "라운드 N · 방 M"(또는 테스트 전투면 "테스트 전투 · 난이도 N") 캡션 + 큰
     턴 배지(`turn_label`, accent색).
   - 우(몬스터): 계열 아이콘(`FamilyIcon`, 보스 왕관/정예 빨간 테두리 그대로 유지) +
     이름 + "일반/정예/보스" 텍스트 배지(색도 회색/빨강/금색으로 구분, 아이콘과
     이중 신호) + 두꺼운 HP 바 + **"특성" 줄**(성격 한 줄 + 보유 스킬의 짧은 이름,
     `_monster_trait_summary_text()` — 다이스 개수 같은 수치는 빼고 사람이 읽기 좋게).
4. **HP 바 두껍게 + 숫자 겹침**: 16px -> `HP_BAR_HEIGHT`(28px), 기존
   `_update_hp_bar()`(색 녹/주황/빨강 전환) 로직은 그대로 두고 `fill`/`label` 참조만
   새 노드로 바꿨다 — 계산/임계값 변경 없음(`m2_before_exchange.png`에서 5/10 =
   정확히 주황 전환 확인).
5. **초상화 재배치/확대**: `combat_test.tscn`에서 player(70,270)->(110,300),
   monster(1210,312)->(1170,300)로 안쪽으로 당기고, 기준 배율도 1.0/1.25 ->
   `PORTRAIT_SCALE_NORMAL`(1.1)/`PORTRAIT_SCALE_BOSS`(1.3)로 키웠다 — 보스 몬스터
   기준 가장자리 여유가 약 24px 생겨 더는 캔버스 밖으로 벗어나지 않는다(계산 근거는
   코드 주석). 다이스 뷰포트 상단도 120->184로 내려 새 HUD 패널과 안 겹치게 했다.
6. **"전투 기록" 구역 패널화**(`_setup_log_panel()`): 기존 평문 `LogLabel`을
   테두리 있는 `UIKit.make_section()` 패널로 감싸고, 맨 위에 **"상태" 요약 줄**
   (`_update_status_panel()` — 캐릭터 기믹별 활성 스택/주기만 골라 보여주고, 없으면
   "활성 효과 없음"으로 명시)을 추가했다. `log_label` 자체(텍스트 갱신 로직)는 그대로
   재사용 — 부모만 바뀜.
7. **버튼 스타일 통일**(`_style_result_buttons()`): "다음"은 `UIKit.
   style_primary_button`, 나머지 5개(다시하기/설정으로/스킬도감/커스터마이징/덱보기)는
   `style_secondary_button` — dungeon_map M-1과 같은 위계.
8. **QA 캐릭터 전환 훅 확장**: `_debug_qa_character_pirate/shieldbearer`가
   `_debug_set_character()` 공용 구현으로 묶이고, 배경/제목뿐 아니라 HUD 패널 3개/로그
   패널/버튼 스타일까지 다시 그리도록 확장(HUD가 전부 런타임 생성이라 M-1 이전처럼
   "배경색만 바꾸기"로는 부족해짐).

### 라운드 2 — After 비평

캡처: 전투 시작 직후(견습 모험가, 일반 슬라임), 교환 1회 후(HP 바 색 전환 확인), 보스
방(room_override=4), 정예 몬스터(monster_id_override=goblin_chief), 해적(밝은 색,
QA 캐릭터 전환 훅), 덱 보기 토글, 승리 보상 화면(스모크 테스트) — 총 7장,
`qa_out/m2_before_*.png`.

- 제목 "전투"로 깔끔해짐, 디버그 줄이 에디터 빌드에서도 구석 10px로 격하되고 성격/스킬
  정보는 "특성" 패널에 사람이 읽기 좋은 문장으로 중복 노출 — **상 해결**.
- 좌/중앙/우 3구역이 한눈에 분리되고 HP 바가 두꺼워져 숫자+색이 동시에 보임, 5/10에서
  정확히 초록->주황 전환 확인 — **상/중 해결**.
- 몬스터 계열 아이콘 + 텍스트 배지(일반/정예/보스) 이중 신호로 정예(빨강 테두리+빨강
  배지)/보스(왕관+금색 배지)가 분명히 구분됨 — **중 해결**.
- 라운드/방 번호 + 턴 배지가 중앙에 자리잡아 "지금 뭘 하고 있는지"가 분명해짐 —
  **중 해결**.
- 보스(1.3배) 포트레이트가 더는 화면 밖으로 안 나감(오른쪽 여백 약 24px 확인),
  일반/정예 포트레이트도 안쪽으로 당겨져 다이스 영역과 자연스럽게 겹침 — **중 해결**.
- "전투 기록" 패널이 테두리를 얻고 맨 위 "상태" 줄이 생겨 다른 화면과 통일된 느낌 +
  스킬 상태 요약 요구 충족 — **중 해결**.
- 버튼 6개가 주/보조 위계로 통일(다음=캐릭터색 꽉 채움, 나머지=테두리) — **하 해결**.
- 덱 보기 토글(z_index 10)과 승리 보상 화면(M-3 영역) 둘 다 새 HUD와 레이아웃 충돌
  없이 공존 확인(크래시/겹침 없음) — 신규 문제 없음.

**남은 "하" 수준 문제** (다음 라운드로 넘김, 더 고치지 않음):
- `GAME_QA_ROOM_OVERRIDE` 전용 레거시 몬스터 순환 경로(`legacy_cycle_monster()`)의
  이름에 "다크 나이트 [철벽] [보스]"처럼 괄호 태그가 남아있어 새 "특성"/티어 배지와
  일부 중복된다 — 이 경로는 QA 전용(`GAME_QA_ROOM_OVERRIDE`)이고 정상 플레이
  (`RunState.monster_plan` 기반)는 애초에 괄호 태그가 없는 이름을 쓰므로 실제
  플레이어는 보지 못하는 문제. 이름 포맷 자체는 몬스터 데이터 레이어 문제라 M-2(UI
  레이아웃) 범위 밖.
- 커스터마이징 버튼이 숨겨진 전투 중(스킬도감/덱보기 사이)에 빈 간격이 남는다 —
  동적 재배치보다는 지금처럼 고정 칸을 두는 쪽이 전투 중/후 레이아웃이 안 흔들려
  낫다고 판단, 간격 자체는 시각적으로 거슬리지 않는 수준.
- 몬스터 "특성" 줄이 성격 문장이 길면(예: 정예 "고블린 족장") 2줄로 줄바꿈돼 몬스터
  패널이 플레이어/중앙 패널보다 눈에 띄게 길어진다 — 패널마다 높이가 다른 것 자체는
  다른 화면(M-1의 MapStrip 카드 등)에서도 쓰는 패턴이라 깨진 것으로 보이진 않지만,
  텍스트가 아주 긴 몬스터가 늘어나면 재검토 여지가 있음.

남은 문제가 전부 "하" 수준이라 M-2는 이 라운드에서 종료.

### Before/After 요약

**Before**: 개발용 제목/디버그 줄이 항상 노출, HP가 얇은 바+별도 텍스트로 분리,
몬스터 계열/티어/성격 정보가 디버그 줄에 뒤섞임, 턴 표시뿐 라운드/방 정보 없음,
초상화가 가장자리에 붙어(특히 보스) 잘릴 위험, 로그가 테두리 없는 평문, 스킬 상태
요약 자리 없음, 버튼 6개가 민짜 회색.
**After**: "좌=플레이어/중앙=턴·라운드/우=몬스터" 3구역 HUD(두꺼운 HP 바+숫자 겹침,
계열 아이콘+티어 배지+특성 요약), 디버그 줄은 구석 10px로 격하되고 릴리즈 빌드에서
완전히 숨겨짐, 초상화가 안쪽으로 당겨지고 커져 더는 안 잘림, "전투 기록"이 상태 요약
줄을 가진 구역 패널로, 버튼 6개가 주/보조 위계로 통일. M-1이 만든 `UIKit` 공용 헬퍼를
그대로 재사용(INBOX M-4 "새로 복붙하지 말 것" 준수), 전투 규칙/밸런스/FocusNav 키
조작은 전혀 건드리지 않음.
